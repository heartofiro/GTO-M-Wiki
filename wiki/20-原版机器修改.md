# GTO 对原版 GTCEu 机器的修改

> 来源：反编译源码 `com/gtocore/common/data/machines/GTMachineModify.java`（`init()` 方法）。
> GTO 不仅新增大量机器，还对 GTCEu 原版机器进行了结构、配方与过载机制上的调整。

## 配方类型与过载修正

| 原版机器 | 改动 |
| --- | --- |
| 多功能熔炼炉 `MULTI_SMELTER` | 配方类型改为熔炉配方（`FURNACE_RECIPES`）；过载修正器 `UPGRADE_MULTI_SMELTER_OVERCLOCK` |
| 大型化学反应釜 `LARGE_CHEMICAL_REACTOR` | 配方修正器改为 `NO_MODIFIER`（不再自动降耗） |
| 电力高炉 `ELECTRIC_BLAST_FURNACE` | 过载修正器 `UPGRADE_EBF_OVERCLOCK` |
| 热解炉 `PYROLYSE_OVEN` | 过载修正器 `UPGRADE_PYROLYSE_OVEN_OVERCLOCK`；产出粉尘时额外回收 1 个对应微尘（无粉尘产物时回收灰烬微尘） |
| 裂化机 `CRACKER` | 过载修正器 `UPGRADE_CRACKER_OVERCLOCK` |
| 聚爆压缩机 `IMPLOSION_COMPRESSOR` | 过载修正器 `UPGRADE_OVERCLOCK`；额外回收硝石微尘 |
| 蒸馏塔 `DISTILLATION_TOWER` | 过载修正器 `UPGRADE_OVERCLOCK` |
| 真空冷冻机 `VACUUM_FREEZER` | 过载修正器 `UPGRADE_OVERCLOCK` |
| 装配线 `ASSEMBLY_LINE` | 过载修正器 `UPGRADE_OVERCLOCK` |
| 磨粉机/碎岩机（全部电压等级）`MACERATOR` / `ROCK_CRUSHER` | 过载修正器 `UPGRADE_OVERCLOCK` |
| 空气净化器（低压级）`AIR_SCRUBBER` | 过载修正器 `UPGRADE_OVERCLOCK`；新增 tooltip 显示灰烬掉落率（`100 - 50/tier`%）与净化范围（`1 << tier+3` 格） |

## 结构改动

| 原版机器 | 新结构 |
| --- | --- |
| 蒸汽磨粉机 `STEAM_GRINDER` | 3×3×3 青铜砖结构（中央空气 + 控制器），支持蒸汽物品/流体口与蒸汽通风仓 |
| 蒸汽炉 `STEAM_OVEN` | 3×2×3 结构（顶部 3 层火箱，底部中央控制器），青铜砖 + 青铜火箱 |
| 土高炉 `PRIMITIVE_BLAST_FURNACE` | 3×3×4 原始砖结构（中央 3 层空气），支持最多 **5** 个高炉仓 |
| 大型青铜锅炉 `LARGE_BOILER_BRONZE` | 3×3×4 结构：3 层青铜砖 + 火箱（≥5）/流体输入（≥1）/物品输入（≤1），流体输出（≥1），管道 |
| 蒸馏塔 `DISTILLATION_TOWER` | 主结构 3×3 可重复 0-10 层（不锈钢清洁外壳），支持 ME 流体输出仓 |
| 电力高炉 `ELECTRIC_BLAST_FURNACE` | 新增子结构（发热耐热外壳 + 不锈钢框架 + 钢制管道，可装加速仓） |

## 其他改动

- **扫描仪**（`SCANNER`，MV 以上）：扫描物品携带行星数据时解锁对应星球维度（`PlanetManagement.unlock`），同时消耗物品
- **聚变反应堆**（MK6-8，LuV-UHV）：新增 tooltip 显示能量缓冲容量（按 16 口能量仓计算）、完美过载说明与配方类型
- **高性能计算阵列** `HIGH_PERFORMANCE_COMPUTING_ARRAY`：新增 4 条 tooltip（科研系统说明）
- **多功能熔炼炉**：tooltip 改为"可用配方：电力熔炉"

> 注：所有 `UPGRADE_*_OVERCLOCK` 为 GTO 自研的过载算法（`com.gtolib.api.recipe.GTORecipeModifiers`，反编译位于 native 库，具体公式以游戏内为准）。
