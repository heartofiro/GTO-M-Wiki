## 数据来源与说明

- **机器/配方/结构**：反编译 `mods/gtocore-forge-1.20.1-0.5.6-beta.jar` 的 `com/gtocore/common/data/` 与 `com/gtocore/data/recipe/`
- **结构图解**：源码内联 `FactoryBlockPattern`（层矩阵 + 图例）；未内联的机器结构定义在 jar 内 `pattern/<id>.mbs`（二进制，以游戏内 EMI 多方块预览为准）
- **名称/描述**：`assets/gtocore/lang/zh_cn.json` 与 `en_us.json`
- **任务文本**：`config/openloader/resources/quests/assets/gto/lang/zh_cn.json`
- **注意事项**：配方产物/数值类内容未在离线环境验证，游戏中请以 EMI/JEI 为准
